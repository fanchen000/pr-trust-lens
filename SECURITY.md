# Security policy

This tool reports **risk signals**, not verified vulnerabilities. Do not use a
passing scan as approval to expose credentials or run untrusted PR code.

If you find a flaw in this scanner that could mislead users or cause denial of
service, please open a GitHub issue **only when the report contains no secrets,
private repository contents or unpatched exploitable sensitive details**.
For sensitive reports, contact the maintainer privately using GitHub's
repository [Report a vulnerability](https://github.com/fanchen000/pr-trust-lens/security/advisories/new)
feature. Private vulnerability reporting is enabled for this repository.
Do not disclose credentials, exploit details or non-public repository contents
in public issues or discussions. Security vulnerabilities are triaged
separately from ordinary false-positive reports.

Security support currently covers the latest released version only. We do not
promise response times. We welcome minimal sanitized reproductions.
